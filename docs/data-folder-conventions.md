# แนวทางตั้งชื่อไฟล์ในโฟลเดอร์ข้อมูล

**หลักข้อเดียว:** ชื่อไฟล์และโฟลเดอร์ใช้เลขหรือรหัสสั้น ๆ ส่วนชื่อเต็มภาษาไทยเก็บใน JSON

## ทำไม

- **path ยาวเกิน 260 ตัวอักษร:** โปรแกรมบางตัวบน Windows เปิดหรือคัดลอกไฟล์ที่ path ยาวเกิน 260 ตัวอักษรไม่ได้ เช่น Word รุ่นเก่า การแตกไฟล์ zip และการคัดลอกใน Explorer
- **โฟลเดอร์ข้อมูลกินความยาวไปแล้วเกินครึ่ง:** path ของโฟลเดอร์ข้อมูลที่ sync จาก private channel ของ Teams ยาวประมาณ 135–145 ตัวอักษร (ขึ้นกับชื่อผู้ใช้ Windows ของแต่ละเครื่อง) เหลือที่ไว้ใช้ภายในโฟลเดอร์ไม่ถึง 120 ตัวอักษร
- **ตัวอย่างจริง:** ถ้าตั้งชื่อไฟล์ตามชื่อเรื่อง เช่น `เอกสารแนบ\4.1.1_ขออนุมัติหลักสูตร… (หลักสูตรปรับปรุง พ.ศ. 2570).pdf` path เต็มจะยาว **262 ตัวอักษร** ซึ่งเกินแล้ว ถ้าใช้ `เอกสารแนบ\4.1.1.pdf` จะยาว 176 ตัวอักษร
- **แก้ชื่อเรื่องได้โดยไม่กระทบไฟล์:** ชื่อเรื่องแก้บ่อยระหว่างร่างวาระ ถ้าชื่อเต็มอยู่ใน JSON การแก้ชื่อจะไม่ต้องเปลี่ยนชื่อไฟล์ ลิงก์และประวัติเวอร์ชันใน SharePoint จึงไม่หลุด
- **เรียงลำดับง่าย:** ไฟล์เรียงตามเลขวาระเองใน Explorer

## โครงสร้างและชื่อที่ใช้

```
<โฟลเดอร์ข้อมูล>\
├── settings.json
├── threads.json
├── tracking.json
└── สภาวิชาการ\                ชื่อสั้นของประเภทการประชุม (ตั้งในหน้าตั้งค่า)
    └── 2569-05\               ปี พ.ศ.-ครั้งที่ 2 หลัก
        ├── meeting.json
        ├── agenda.json
        ├── minutes.json
        ├── เอกสารแนบ\
        │   ├── 4.1.1.pdf      เลขวาระ
        │   ├── 4.1.1-2.pdf    ไฟล์ที่ 2 ของวาระเดียวกัน
        │   └── 2.1.pdf
        ├── ลับ\
        │   └── 4.3.pdf
        └── เอกสารที่สร้าง\
            ├── เล่มวาระ.docx
            ├── เล่มวาระ.pdf
            ├── รายงาน-ร่าง-v1.docx
            ├── รายงาน-ร่าง-v2.docx
            ├── รายงาน-รับรอง.docx
            └── รายงาน-เผยแพร่.docx   ฉบับตัดวาระลับ
```

## กติกา

| เรื่อง | ใช้ | ไม่ใช้ |
| --- | --- | --- |
| เอกสารแนบ | `4.1.1.pdf`, `4.1.1-2.pdf` | ชื่อเรื่อง ชื่อหลักสูตร ชื่อคณะ |
| โฟลเดอร์ครั้งที่ | `2569-05` | `ครั้งที่ 5-2569`, `5/2569` |
| ไฟล์ที่ระบบสร้าง | ชื่อคงที่ตามตาราง + เลขฉบับ | วันที่หรือชื่อคนในชื่อไฟล์ |
| อักขระ | ตัวอักษร ตัวเลข `.` `-` `_` | `\ / : * ? " < > \| # %` ช่องว่างหน้า/ท้ายชื่อ จุดท้ายชื่อ |

ชื่อเต็มและลำดับของเอกสารแนบเก็บใน `agenda.json`

```json
{
  "items": [
    {
      "no": "4.1.1",
      "title": "ขออนุมัติหลักสูตร… (หลักสูตรปรับปรุง พ.ศ. 2570)",
      "attachments": [
        { "file": "เอกสารแนบ/4.1.1.pdf",   "title": "เล่มหลักสูตรฉบับเต็ม" },
        { "file": "เอกสารแนบ/4.1.1-2.pdf", "title": "ตารางเปรียบเทียบหลักสูตรเดิมและหลักสูตรปรับปรุง" }
      ]
    }
  ]
}
```

**เมื่อสลับลำดับวาระ:** เลขวาระเปลี่ยนตาม แต่ระบบต้องเปลี่ยนชื่อไฟล์แนบให้ตรงกับเลขใหม่ในครั้งเดียวกัน (ระยะ 1) หรือเก็บชื่อไฟล์เดิมไว้แล้วอ้างผ่าน `attachments[].file` เรื่องนี้ค่อยตัดสินใจตอนทำหน้าแก้ไขวาระ

## ตรวจความยาว path

เปิด PowerShell ในโฟลเดอร์ข้อมูล (ใน Explorer คลิกขวาที่ว่าง แล้วเลือก "เปิดใน Terminal") แล้วรัน:

```powershell
Get-ChildItem -Recurse | Sort-Object { $_.FullName.Length } -Descending | Select-Object -First 5 @{n='ความยาว';e={$_.FullName.Length}}, FullName
```

ถ้าไม่เกิน 260 ใช้ได้ทุกโปรแกรม ถ้าเกิน ให้ย่อชื่อโฟลเดอร์หรือชื่อไฟล์
