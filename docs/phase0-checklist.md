**เกณฑ์ผ่าน**

- **เครื่องผู้พัฒนา:** ผ่านข้อ 1.1–1.5 และ 2.1–2.2 ในโหมด B (localhost) แล้วไปต่อระยะ 1 ได้
- **โหมด A (เปิดจากไฟล์):** เป็นข้อมูลประกอบ ถ้าไม่ผ่านก็ไม่ต้องหยุดงาน

## ขั้น 0 — ตรวจนโยบาย Edge (ทุกเครื่อง ทำเองได้ ใช้เวลา 2 นาที)

ถ้ามหาวิทยาลัยตั้งนโยบายบางข้อไว้ ระบบจะเปิดหรือเขียนโฟลเดอร์ไม่ได้ ไม่ว่าโค้ดจะถูกแค่ไหน

1. เปิด Microsoft Edge พิมพ์ `edge://policy` ในช่องที่อยู่ แล้วกด Enter
2. ถ้าหน้าขึ้นว่า **ไม่มีนโยบาย** (No policies set) แปลว่า **ผ่าน** ข้ามไปขั้น 1 ได้เลย
3. ถ้ามีรายการนโยบาย ให้พิมพ์ชื่อด้านล่างทีละชื่อในช่องค้นหาบนหน้านั้น แล้วจดค่าที่เห็น

| นโยบาย | ค่าที่ทำให้ไม่ผ่าน | ผลกระทบ |
| --- | --- | --- |
| `DefaultFileSystemReadGuardSetting` | `2` | เปิดอ่านโฟลเดอร์ไม่ได้ทุกเว็บ |
| `DefaultFileSystemWriteGuardSetting` | `2` | เขียนไฟล์ไม่ได้ทุกเว็บ |
| `FileSystemReadBlockedForUrls` | มี `*`, `github.io` หรือ `localhost` | เปิดโฟลเดอร์จากเว็บนั้นไม่ได้ |
| `FileSystemWriteBlockedForUrls` | มี `*`, `github.io` หรือ `localhost` | เขียนจากเว็บนั้นไม่ได้ |
| `AllowFileSelectionDialogs` | `false` | หน้าต่างเลือกโฟลเดอร์ไม่ขึ้น |
| `DefaultCookiesSetting` | `2` หรือ `4` | ระบบจำโฟลเดอร์ไม่ได้ ต้องเลือกใหม่ทุกครั้ง |
| `ClearBrowsingDataOnExit` | `true` | ปิด Edge แล้วลืมโฟลเดอร์ |
| `DownloadRestrictions` | `3` | ดาวน์โหลดไฟล์ Word ไม่ได้ (ยังบันทึกลงโฟลเดอร์ได้) |

4. ไปที่ `edge://settings/content/fileEditing` (ถ้ามีหน้านี้) แล้วดูว่าไม่ได้ปิดหรือบล็อกไว้
5. ถ้าพบค่าที่ทำให้ไม่ผ่าน ให้ถ่ายภาพหน้าจอแถวนั้นไว้ (คอลัมน์ "แหล่งที่มา" บอกว่ามาจากเครื่องหรือจากคลาวด์) แล้วส่งให้ผู้ดูแลระบบ

**ทางเลือก:** ใช้ PowerShell ดูนโยบายที่ตั้งบนเครื่อง (นโยบายจากคลาวด์จะไม่แสดงที่นี่ จึงควรใช้ `edge://policy` เป็นหลัก)

```powershell
reg query "HKLM\SOFTWARE\Policies\Microsoft\Edge"; reg query "HKCU\SOFTWARE\Policies\Microsoft\Edge"
```

## สรุปผลเครื่อง 1 (10–11 พ.ย. 2569)

เครื่อง 1 คือ Windows 11, Edge 157, Word ของ Microsoft 365 **ผ่านเกณฑ์ ไปต่อระยะ 1 ได้**

- **โหมด B (localhost แทน GitHub Pages):** ผ่านทุกข้อที่ทดสอบ เมื่อเลือก "อนุญาตทุกครั้ง" แล้ว ปิดและเปิด Edge ใหม่จะได้สิทธิ์ทันทีโดยไม่ต้องกดอะไร
- **โหมด A (file://):** จำโฟลเดอร์ได้ แต่กล่องถามสิทธิ์มีแค่ Allow / Don't Allow จึงต้องกด "เชื่อมต่อโฟลเดอร์เดิม" แล้วกด Allow ทุกครั้งที่เปิด Edge ใหม่ เพราะทุกไฟล์ที่เปิดจากเครื่องใช้แหล่งที่มาเดียวกันคือ `file:///` ถ้า Edge จำสิทธิ์ให้ ไฟล์ HTML อื่นในเครื่องจะได้สิทธิ์ไปด้วย **สรุปว่าใช้ GitHub Pages เป็นหลัก** และเก็บโหมด A ไว้เป็นทางสำรอง
- **ตัดคำไทยใน Word:** ข้อความไทยทุกช่วงต้องติด `<w:cs/>` (complex script) ถ้าไม่ติด Word จะไม่ใช้พจนานุกรมไทย ทำให้ตัดบรรทัดกลางคำ ยืดตัวอักษรห่าง และขีดเส้นหยักแดงใต้ทุกคำ การตั้งภาษาเป็น th-TH อย่างเดียวไม่พอ แก้แล้วใน `phase0/docx.js`
- **เขียนทับไฟล์ที่เปิดใน Word:** ไม่ได้ Edge แจ้ง `InvalidStateError` และไม่มี `.crswap` ค้าง ไฟล์เดิมไม่เสีย ระบบจริงจึงควรสร้างฉบับใหม่ (`-v2`, `-v3`) แทนการเขียนทับ และแจ้งให้ปิดไฟล์ใน Word เมื่อเขียนไม่ได้
- **Word แก้ไฟล์ในโฟลเดอร์ข้อมูลเอง:** หลังเปิดไฟล์ที่ระบบสร้างใน Word ขนาดไฟล์เปลี่ยนจาก 24,846 เป็น 36,102 ไบต์ ยังไม่ยืนยันว่าเกิดจาก AutoSave หรือมีคนกดบันทึกเอง ระบบจริงต้องถือว่าไฟล์ Word ในโฟลเดอร์ถูกแก้จากภายนอกได้เสมอ
- **เลือกโฟลเดอร์ผิด:** หน้าต่างเลือกโฟลเดอร์อาจเปิดขึ้นที่โฟลเดอร์โปรเจกต์ ระบบจริงควรตรวจว่ามี `settings.json` และเตือนเมื่อโฟลเดอร์ที่เลือกไม่ใช่โฟลเดอร์ข้อมูล
- **ยังไม่ได้ทดสอบ:** sync ขึ้น Teams และการอ่านไฟล์ที่ทำ Free up space ไว้ ทั้งสองข้อทำเพิ่มได้ระหว่างระยะ 1
